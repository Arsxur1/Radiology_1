# Сертификат шлюза (HTTPS)

Сюда кладутся `server.crt` и `server.key` — шлюз при запуске включает HTTPS (порты 443 и
3000), а HTTP перенаправляет. Без них шлюз работает по HTTP и пишет предупреждение.

- Свой сертификат клиники: скопируйте файлы сюда под этими именами.
- Нет своего: `make tls-cert HOST=<IP сервера>` — создаст центр сертификации клиники
  (`ca.crt`, `ca.key`) и сертификат сервера. `ca.crt` установите на рабочие места
  врачей (доверенные корневые центры, можно групповой политикой) — тогда браузер не
  предупреждает. `ca.key` храните отдельно, в сейфе.

Файлы ключей в git не попадают (`.gitignore`).
