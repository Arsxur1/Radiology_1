# Рабочее место врача (frontend)

React + TypeScript + Vite. Реализует интерфейс процесса FR-9 и центральный
инвариант ТЗ (раздел 11): явное разделение «система посчитала / врач подтвердил».

## Ключевые решения интерфейса

- **Находка модели ≠ подтверждённая находка.** Результат ИИ показывается с
  заметным бейджем «черновик ИИ — требует подтверждения» (`FindingCard.tsx`).
- **Нет «принять всё».** Каждое решение (подтвердить / изменить / отклонить) —
  отдельное действие по одной находке (SR-2, SR-6).
- **Фиксация времени.** Затраченное врачом время считается от появления карточки
  и уходит в `correction` (обучающий сигнал, FR-9).
- **Баннер режима** (`ModeBanner.tsx`): в RESEARCH/SHADOW явно маркирует
  «не для клинического применения» / «результаты не отображаются» (раздел 2).
- **Заключение** собирается только из подтверждённых находок; финализация —
  активное действие врача (FR-8).

Просмотр изображений (MPR, 3D, оконные пресеты) выполняет OHIF Viewer
(`../frontend/config/ohif.js`); это приложение — рабочий процесс правок и заключения.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173, проксирует /api → backend :8000
npm run build      # прод-сборка (strict TypeScript)
npm run typecheck
```

## Аутентификация

- Продакшн: Bearer-токен OIDC Keycloak.
- Стенд: X-Debug-идентификация (работает только при `ALLOW_DEBUG_AUTH=true` на backend).

См. `src/auth.ts`, `src/api/client.ts`.
