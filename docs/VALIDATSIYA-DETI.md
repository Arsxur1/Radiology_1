# Проверка рентген-модели на детях (открытые наборы)

Проверено 1 октября 2026. Модель, предобработка (`classification.xrv_tensor`), коды
словаря и пороги — **те же, что у кандидата в платформе**; скрипт
`backend/scripts/eval_pediatric_cxr.py`, логика `app/training/pediatric_eval.py`.
Полные агрегаты — `docs/validatsiya/*.json` (без изображений и построчных данных; с хешами весов —
их можно загрузить в админке как свидетельство кандидата: «Загрузить внешнюю детскую проверку»).
Повторный прогон 2 октября дал те же значения до последнего знака (воспроизводимо).

## Наборы (оба CC BY 4.0, коммерческое использование допустимо)

| Набор | Дети | Снимки | Метки | Источник |
|---|---|---|---|---|
| Guangzhou (Kermany), версия PneumoniaMNIST+ 224×224 | 1–5 лет | test 624 (234 норма / 390 пневмония); train 4 708 — только для подбора порогов | норма / пневмония | Zenodo 10519652, md5 сверен |
| **HWCMC, Hainan** — другая больница | **0–14 лет** | 5 632: норма 2 291, бактериальная 1 108, смешанная 1 330, микоплазменная 603, вирусная 300 | норма / тип пневмонии | Zenodo 13744272, md5 сверен |

Метки — диагнозы. Модель на них не учится и диагноз не выдаёт (SR-1). Проверяется, как
**находки-черновики, которые увидит врач**, ведут себя на настоящих детских снимках.

## Результаты

AUROC «есть ли что-то» — максимум вероятностей по видимым врачу кодам против «пневмония»
(95% ДИ — бутстреп). «Здоровых с черновиком» — доля нормы, где врач увидит хотя бы одну
находку ИИ (лишняя работа и риск ложной тревоги).

| Веса | Набор | AUROC [95% ДИ] | Здоровых с черновиком | Пневмоний с черновиком |
|---|---|---|---|---|
| `-nih` (коммерчески допустимые) | Guangzhou test | 0,847 [0,813–0,882] | **51,7 %** | 97,7 % |
| `-nih` | **HWCMC** | **0,641** [0,625–0,655] | 53,7 % | 75,8 % |
| `-all` (только исследования) | Guangzhou test | 0,929 [0,907–0,950] | 19,7 % | 93,1 % |
| `-all` | **HWCMC** | **0,660** [0,647–0,675] | 16,2 % | 39,0 % |

**«Образование (mass)» у здоровых детей.** С весами `-nih` при исходных порогах этот код
появляется у **48,7 %** здоровых детей Guangzhou (у пневмонии — 93,6 %). Выход модели «Mass»
реагирует на детскую анатомию или любое затенение, а врач увидел бы «образование» у каждого
второго здорового ребёнка. Причина: у весов `-nih` нет рабочих точек авторов, и все пороги
— запасные 0,55, рассчитанные не на детей.

### Подбор порогов по здоровым детям

Пороги кодов поднимаются так, чтобы каждый код давал черновик не более чем у r % здоровых
детей части **train**. Пороги никогда не опускаются; проверка идёт на части **test**, которой
подбор не видел.

| `-nih` | Здоровых с черновиком | Пневмоний с черновиком |
|---|---|---|
| исходные пороги | 51,7 % | 97,7 % |
| r = 1 % | 11,5 % | 78,7 % |
| **r = 2 %** | **16,7 %** | **87,9 %** |
| r = 5 % | 20,5 % | 93,3 % |

«Образование (mass)» у здоровых при r = 2 % — 4,7 % (было 48,7 %).

### Перенос порогов в другую больницу (HWCMC, без изменений)

| Пороги Guangzhou, r = 2 % | Здоровых с черновиком | Пневмоний с черновиком |
|---|---|---|
| `-nih` | 23,8 % (на Guangzhou — 16,7 %) | 50,4 % (было 87,9 %) |
| `-all` | 1,8 % | 12,0 % |

Снимки HWCMC просмотрены выборочно (по одному на класс): полярность верная, не
инвертированы, обычные клинические кадры с маркерами и электродами, есть младенцы.
Падение качества — **не артефакт данных**.

## Выводы

1. **Результаты на Guangzhou оптимистичны.** На второй детской больнице с возрастом 0–14
   лет открытые модели различают норму и пневмонию слабо (AUROC 0,64–0,66), в том числе
   коммерчески допустимая `-nih`.
2. **Пороги не переносятся между больницами.** Подобранные на одной площадке, на другой они
   дают иной баланс лишних черновиков и пропусков. Калибровка должна идти на данных самой
   площадки — в платформе это «Калибровка по площадке» по подписанным заключениям NCMC.
3. **Порядок работы подтверждён:** открытые модели — только **SHADOW** на NCMC (врач их не
   видит), продвижение в ASSIST — только по свидетельствам площадки (гейт: теневой прогон,
   срезы по аппаратам и **возрастным группам**). Без этого врач NCMC получил бы черновики
   примерно у каждого второго здорового ребёнка.
4. **Для продукта нужна дообученная модель на данных NCMC.** Открытые детские наборы
   (HWCMC, Guangzhou — CC BY 4.0, коммерция допустима) пригодны для педиатрической адаптации
   и как постоянный внешний тест каждого кандидата, но не заменяют данные площадки.
5. Код «Образование (mass)» для `-nih` у детей вводит в заблуждение. До калибровки по площадке
   — кандидат исключать этот код из черновиков или переименовывать для педиатрии; решение
   за врачами NCMC.

## Ограничения

- Метки обоих наборов — диагнозы (норма / пневмония), а не находки: «пневмония с
  черновиком» не означает, что черновик назвал верную находку.
- Guangzhou взят в версии 224×224 MedMNIST+ (уменьшение выполнено авторами MedMNIST до
  нашей центральной обрезки); HWCMC — исходные PNG 893×893.
- Микоплазменная и смешанная пневмонии могут давать неяркую рентгенологическую картину —
  часть «пропусков» может быть ожидаемой и для врача.

## Повторить

```bash
# Guangzhou: подбор порогов на train, проверка на test
python scripts/eval_pediatric_cxr.py --npz pneumoniamnist_224.npz --splits test --calibrate-split train \
    --weights densenet121-res224-nih densenet121-res224-all --out guangzhou.json
# HWCMC: все снимки, с порогами Guangzhou без изменений
python scripts/eval_pediatric_cxr.py --data "Pediatric Pneumonia" --splits \
    --weights densenet121-res224-nih densenet121-res224-all --apply-calibration guangzhou.json \
    --dataset-name "HWCMC (0–14 лет)" --out hwcmc.json
```
